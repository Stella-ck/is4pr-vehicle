管理员说明

  • 01
    登录

    生产环境使用 Supabase Auth 邮箱密码登录；演示模式提供临时演示账号。

  • 02
    编辑

    登录后双击任意单元格即可编辑，按 Enter 保存，按 Esc 取消。

  • 03
    新增 / 删除

    使用“新增行”添加空白记录，点击行尾的删除按钮移除记录。

  • 04
    部署

    将此目录上传到 GitHub，开启 GitHub Pages；填写 Supabase 配置即可切换到线上数据。
